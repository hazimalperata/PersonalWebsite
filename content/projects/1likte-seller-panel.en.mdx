## Overview

I built the 1likte seller panel from scratch. Merchants use it to manage products, track orders and see live updates in the interface. I designed the frontend architecture to keep the code maintainable as the panel grows.

## What it does

- Product management: add, edit and delete products, manage inventory and upload images.
- Order tracking: live updates for order statuses and notifications.
- Responsive pages built from the Figma designs.
- Role-based access control and secure login flows.

## Stack

Next.js, React, TypeScript, Tailwind CSS, Zustand and React Query.

## Challenges

Keeping the components clean and reusable as the panel grew was the main challenge. Turning complex Figma designs into interactive React components meant careful work and testing on many devices.
