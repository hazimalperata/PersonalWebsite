## Overview

I built the 1likte landing page from scratch to present the platform's features and bring in new users. It follows the Figma designs, works on mobile, and is set up for search engines.

## What it does

- Responsive layout: the Figma designs became mobile-friendly pages.
- SEO: metadata, semantic HTML and structured content help search engines index it.
- Interactive sections: animations, feature highlights and call-to-action components.
- Localization: the site is prepared for multiple languages.

## Stack

Next.js, React, TypeScript and Tailwind CSS.

## Challenges

Keeping load times fast while staying true to the designs was the main challenge. I also worked on accessibility and cross-browser compatibility.
