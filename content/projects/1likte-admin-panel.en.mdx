## Overview

I built the 1likte admin panel from scratch. Administrators use it to manage users, watch analytics and run day-to-day operations. I turned the Figma designs into working interfaces.

## What it does

- Manages users, with role-based access and admin controls.
- Shows operational data in an analytics dashboard.
- Runs on a reusable component library I built for it.

## Stack

Next.js, React, TypeScript and Tailwind CSS, with server-side rendering.

## Challenges

The data tables and dashboards are complex, so I had to balance performance against usability. Keeping access secure without making the interface sluggish was the other hard part.
