## Overview

*Adventures Of The Knight* is a 2D platformer I made in Godot to learn game development by building something playable, and as a first step into the game industry.

The loop is simple: run, jump, stomp enemies, and collect coins through handcrafted levels.

## What it has

- Movement, jumping, and physics-based platform interactions.
- Enemies you defeat by jumping on top of them, as in classic platformers.
- Coins placed through the levels for exploration and score.
- Several handcrafted levels with rising difficulty.
- Character and environment animations.
- Background music and sound effects.
- A main menu and a pause menu.
- Mobile and desktop builds, with input handling for keyboard and touch.

## Built with

- Godot Engine and GDScript
- Godot's 2D physics
- Control nodes for the UI
- The Godot audio server

## What I learned

The hardest part was structuring a Godot project: managing scenes, player state, and level transitions. Controls that work on both mobile and desktop also took some input design.

Along the way I got hands-on with game loops, collision systems, animation handling, and basic game architecture.
