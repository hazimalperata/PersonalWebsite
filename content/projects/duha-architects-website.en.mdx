## Overview

I designed and built the website of an architecture studio. It is minimal, with large typography and a clear visual hierarchy, so the architectural work stays in front.

## Approach

I used one layout system across all pages to keep them consistent, and spent time on spacing, transitions, and responsiveness so the site works on every device. Navigation between projects and content is kept simple.

## What it has

- A project showcase with high-quality visuals.
- A minimal interface focused on content.
- Layouts for desktop, tablet, and mobile.
- Subtle animations and transitions.
- Clear sections for projects, studio information, and contact.
- Multiple languages through next-intl.

## Built with

Next.js, React, TypeScript, Tailwind CSS, and next-intl.

## What I learned

Large media files had to be optimized carefully to keep loading fast without visible quality loss. The other challenge was a layout system flexible enough for different project types while staying consistent.
