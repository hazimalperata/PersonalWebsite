## Overview

I built the 1likte mobile app with Expo and React Native, turning the Figma designs into working screens. It has navigation, offline support, API integration and push notifications, and it runs on iOS and Android.

## What it does

- Covers the platform's screens and navigation flows.
- Keeps working through network interruptions.
- Ships through both app stores, and I handle submission and release.

## Stack

React Native, Expo SDK, TypeScript, Expo Router and push notification APIs.

## Challenges

Keeping performance, responsiveness and maintainable code in balance across two platforms took work. Offline cases and asynchronous API calls called for careful state management.
